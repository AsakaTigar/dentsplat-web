测到了什么，没测到什么

已测量（同一台机器、同一份构建，脚本可复算）

  • 体积 4.24× / 3.43×（完整包 → 剪枝包）
  • 像素保真 21.82 / 17.60 dB（A）、25.10 / 22.03 dB（B），整帧 / 掩膜内
  • 剪枝策略 A/B：+4.63 / +4.85 dB，亮度损失 14% → 4%
  • 几何覆盖间隙 0.314 / 0.691 mm（A）、0.349 / 0.946 mm（B，p95）
  • GPU 单遍 0.5–2.9 ms，640×360 到 2560×1440 几乎与分辨率无关
  • 离线链路 NIfTI → .dspk：46 项断言，重跑逐字节相同

尚未测量（不要用本视频替代这些结论）

  • 资产是合成的：几何按公开数据集统计生成，颜色与病灶程序化
  • 离线链路用的是合成体数据，不是患者；Blender 渲染与真实训练产物后处理未跑过
  • "阻生智齿是否压迫下牙槽神经管"目前只是可做的交互，还不是结果
  • 耗时不含合成与上屏；低端 GPU 与远程桌面未实测
  • 毫米测距是水面距离；无任何临床诊断验证
