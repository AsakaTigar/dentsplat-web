日期 2026-11-25
环境 RTX 5070 Ti / ANGLE-D3D11 / Chromium 150
状态 渲染与编码链路已测量 A 真实扫描 · B 合成

一句话：把牙科数据压进一个自描述容器 .dspk，在浏览器里用一次 draw call 画出来， 并且让每一个交互、每一个数字都能被脚本重新测出来——随附的 60 秒走查只是把这些数字念出来，字幕里的每个数值仍由同一批脚本复算。

① 数据 → 容器

两条真实数据形态的路线：Scene A 走表面网格（Teeth3DS / 3DTeethSeg 的 OBJ + 逐顶点 FDI 标注）， Scene B 走 CBCT 分割体（ToothFairy3 的 77 类 NIfTI）。离线管线 pipeline/run_case.sh 产出渲染图 + COLMAP 位姿 + 代理网格 + fdi/layer_labels.bin，训练后由 tools/ply2dspk.ts 封成 .dspk。

② 容器里写了什么

128 B 头 + 内嵌 JSON 元数据 + 每 splat 20/29 B：位置在 bbox 内 u16 插值、旋转 snorm、尺度 log 域 u8、 颜色 u8，第四个字节带 FDI 与语义层标签。标签随点走而不是外挂，因为 ksplat / spz 的 Morton 重排会让旁挂标签错位——这正是牙位定位能不能做对的分水岭。

③ 交互在着色器里

牙弓开合、X/Y/Z 三轴剖切加断面盖片、按层透明度的 X 光模式、点选高亮与二维牙位图双向联动、毫米级测距、 Full / Pruned 同屏对比、性能 HUD。裁剪与高亮是 uniform 级实现，不是黑盒库， 所以能被脚本逐层验证。

5为什么这件事值得用 3DGS，而不是 Mesh 或体渲染

  • 同一个文件既能画又能定位。标签在 splat 里，点一下就知道是 36 号牙、是牙根还是根管， 不必另维护 mesh-tooth 映射；Mesh 路线要重网格或逐面片属性，体渲染路线要在图像空间反查解剖。
  • 成本与分辨率解耦。0.5–2.9 ms 的单遍开销从 360p 到 1440p 基本不变，瓶颈是顶点与排序而非填充率； 在这台 5070 Ti 上相对 60 fps 预算余量约 5×（A 完整包 1440p）到 12×（剪枝包），CPU 排序 0.9–2.3 ms 也放得进 16.6 ms。 低端集成显卡与远程桌面尚未实测，但这条曲线形状说明它不是填充率受限的场景；体渲染的光线步数则随分辨率线性上涨。
  • 半透明是原生能力。釉质/牙根/神经管/上颌窦的分层透视由一个 uLayerAlpha 数组驱动， 拉动滑块就能把牙根与下牙槽神经管的上下关系显示出来（是否"压迫"要真实病例，见第 7 节）； Mesh 要穿透遮挡，体渲染要为透明重排采样。

6与课题组临床问题的接口

  • 牙位定位：FDI 编号贯穿 OBJ 顶点标签 → 训练点云 → .dspk 第四字节 → 点击高亮 → 二维牙位图，每一跳都有断言；CBCT 侧根管沿用 FDI + 100， 所以"点牙冠亮整颗牙含根管"不需要旁挂文件。
  • CBCT 高效阅读：六个语义层（牙槽骨 / 牙体 / 神经管 / 牙髓 / 修复体 / 上颌窦）分别可调可隔离， 测量给出真实毫米数。
  • 可核查证据：界面里的证据卡记下每个结论的来源、判据与失败条件——与我在 BIBM 上的证据审计工作连成一条线： 没有可复算出处的数字就写作待测，不写进结论。

7 · 这份简报不证明什么（先说清楚，免得后面被动）

  • 两个场景的几何都是真实公开数据，外观不是：A 是 Poseidon3D 一例真实口内扫描（CC BY 4.0，单侧下颌，逐面 FDI），B 是 DentVoxel 一例真实患者 CBCT（case 0095，440×440×344 / 0.3 mm，CC BY 4.0，39 类标注）。A 的 gsplat 3DGS 与 2DGS 已在同一 COLMAP 划分上真实训练并审计（见第 4 节新表），但训练图像的外观仍由 Blender 灯光渲染，不是患者口内照片；B 列仍是几何采样。随附的 60 秒走查拍于合成资产时代，片头仍标 SYNTHETIC PREVIEW。
  • 离线 CBCT 链路用的是合成体数据（解析标注的 fixture 体积），不是患者；Scene A 前端的 Blender 渲染与 postprocess_dental_gs.py 尚未在真实训练产物上跑过，本机也没有 Blender。
  • 耗时只含 GPU 渲染遍与 CPU 排序，不含合成与上屏，且测于隐藏自动化窗口，不用于宣称帧率；Scene A 的真实扫描包（59,808 splats）单遍耗时低于该仪器的分辨率下限（≤1 ms），因此不给具体值。 毫米测距打在隐形代理网格上，是水面距离而非 splat 质心距离。"拉动滑块看阻生智齿牙根是否压迫下牙槽神经管"目前只是可做的交互， 还不是结果：合成 fixture 里的牙根与神经管并不相邻，真实 ToothFairy3 病例上还没有可测样例；也没有任何临床诊断验证。
